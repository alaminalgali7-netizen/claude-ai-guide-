# Claude AI — Arabic Guide

موقع تعريفي عربي عن Claude AI من شركة Anthropic. المشروع مبني باستخدام HTML وCSS وJavaScript فقط، ولا يحتاج إلى تثبيت حزم أو إعداد خادم.

## ✨ المميزات
- تصميم عربي RTL ومتجاوب مع الهاتف والكمبيوتر.
- أقسام تعريفية عن Claude واستخداماته.
- مقارنة عامة بين Claude وChatGPT.
- قسم للاستخدام المسؤول وأسئلة شائعة.
- زر لتبديل الوضع الفاتح والداكن.
- زر لنسخ مثال Prompt.

## 🚀 تشغيل المشروع محلياً
1. حمّل ملفات المشروع.
2. افتح `index.html` في المتصفح.
3. لا توجد خطوات تثبيت إضافية.

## 📁 هيكل المشروع
```text
claude-ai-github-project/
├── index.html
├── style.css
├── script.js
└── README.md
```

## 🌐 النشر على GitHub Pages
1. أنشئ Repository جديداً على GitHub.
2. ارفع الملفات الأربعة إلى المستودع.
3. افتح **Settings → Pages**.
4. من **Build and deployment** اختر **Deploy from a branch**.
5. اختر فرع `main` والمجلد `/ (root)` ثم اضغط **Save**.
6. انتظر ظهور رابط الموقع في صفحة Pages.
